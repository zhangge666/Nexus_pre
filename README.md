# Nexus · 你的第二大脑产品家族

> Echo · Muse · Quill · Orbit
> 记录一切，理解一切，让知识不断环绕回来。

Nexus 是一个以「中枢记忆库」为核心的跨端产品家族。它由四款各司其职的软件组成，通过一套统一的记忆协议（Memory Protocol）互相打通，同时对外开放，可以对接任何有信息记录需求的应用。

---

## 一、产品家族全景

| 软件 | 中文名 | 意象 | 一句话定位 |
|------|--------|------|-----------|
| **Echo** | 屏幕记忆 | 回声，过去的回响 | 一键抓取屏幕主要信息，沉淀为可检索的记忆 |
| **Muse** | 灵感捕捉 | 缪斯，灵感女神 | 呼之即来挥之即去的极速速记与语音记录 |
| **Quill** | 笔记系统 | 羽毛笔，书写的象征 | 帮助学习、记忆、理解的智能 Markdown 编辑器 |
| **Orbit** | 智能复习 | 轨道，知识环绕回归 | 中枢记忆库 + 知识卡片 + 间隔复习的第二大脑 |

### 它们的关系

```
                        ┌───────────────────────────────┐
                        │            使用者              │
                        └───────────────────────────────┘
             捕获层 (Capture)                          消费层 (Consume)
   ┌──────────┬──────────┬──────────┐          ┌──────────────────────────┐
   │   Echo   │   Muse   │  Quill   │          │          Orbit           │
   │ 屏幕记忆 │ 灵感捕捉 │ 笔记系统 │          │  中枢记忆库 / 智能复习    │
   └────┬─────┴────┬─────┴────┬─────┘          └────────────┬─────────────┘
        │          │          │                             │
        │   写入记忆 (ingest)  │                    检索/复习/卡片 (query)
        └──────────┼──────────┘                             │
                   ▼                                         ▼
        ╔══════════════════════════════════════════════════════════════╗
        ║              Memory Protocol  ·  记忆协议 (统一接口)            ║
        ╠══════════════════════════════════════════════════════════════╣
        ║   nexus-core  (Rust 共享核心)                                  ║
        ║   存储引擎 · 向量检索 · 加密 · 同步 · AI Provider 抽象          ║
        ╚══════════════════════════════════════════════════════════════╝
                   ▲                                         ▲
                   │  外联 (external)                        │
        ┌──────────┴───────────┐              ┌──────────────┴───────────┐
        │  第三方 App / 脚本    │              │  AI 助手 (MCP) / 浏览器扩展 │
        └──────────────────────┘              └──────────────────────────┘
```

- **Echo / Muse / Quill 是「捕获层」**：从不同场景把信息喂进记忆库。
- **Orbit 是「中枢 + 消费层」**：它既是记忆库本体，也提供检索、知识卡片、间隔复习。
- **Memory Protocol 是纽带**：四款软件通过它「内联」，第三方应用通过它「外联」。

> **关键设计原则：Orbit 不是前三者的私有大脑。** 它是一个开放的记忆中枢，Echo/Muse/Quill 只是它的第一批「一等公民」客户端。任何应用都能通过 Memory Protocol 写入与检索。

## 二、核心理念

### 1. 本地优先，隐私为本 (Local-first)
数据默认全部存在你自己的设备上，端到端加密。云同步是可选项，且服务端永远拿不到明文。你的第二大脑，属于你。

### 2. 呼之即来，挥之即去 (Frictionless)
捕获信息的成本必须趋近于零。全局快捷键、极速唤起、后台静默。想法在脑中停留的时间越短越好。

### 3. 可插拔的智能 (Pluggable AI)
本地小模型负责隐私敏感、高频、离线的任务（嵌入、OCR、语音转写）；云端大模型负责复杂生成（总结、卡片、问答）。用户可自由切换、自带 API Key，甚至纯离线运行。

### 4. 开放优于封闭 (Open over closed)
记忆不应被锁死在某个 App 里。统一的数据模型 + 开放协议 + SDK，让记忆可以自由流入流出。

## 三、技术栈一览

| 层 | 选型 | 理由 |
|----|------|------|
| 桌面 + 移动外壳 | **Tauri 2.0** | 一套代码覆盖 Win/macOS/Linux/iOS/Android；包体极小（契合 Muse）；Rust 侧性能与安全 |
| 共享核心 | **Rust (`nexus-core`)** | 存储、向量检索、加密、同步一次实现，四端复用 |
| 前端 UI | **React + TypeScript + Vite** | 生态成熟，四款软件共享设计系统与组件库 |
| 本地存储 | **SQLite + sqlite-vec** | 单文件、事务安全、内置向量检索 |
| 本地 AI | **Candle / ONNX Runtime + Whisper** | Rust 原生推理，嵌入与语音本地化 |
| 云 AI | **Provider 抽象层** | 支持 Claude / OpenAI / 自定义端点，用户自带 Key |
| 同步 | **端到端加密的 CRDT 同步** | 混合模式：本地优先 + 可选云中继 |

> 详见 [`docs/architecture.md`](docs/architecture.md)。
