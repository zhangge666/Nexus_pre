# Muse · 随叫随到的工作助手 —— 功能说明与界面定义

> 意象：缪斯不是一本需要主动打开的笔记本，而是在念头、任务、会议和资料之间随叫随到的助手。
>
> 一句话定位：**用自定义快捷键直达当下需要的工具，接住想法、工作上下文、会议内容和剪贴板片段。**

Muse 是 Nexus 产品家族中最小巧的助手型软件。它不要求用户先进入一个复杂工作台，再寻找功能；日常入口是系统级自定义快捷键，每个快捷键都能直接唤起一个专用的紧凑浮层。用户完成当前动作后，窗口可以立即隐藏，但内容、来源和时间线仍被可靠保留。

Muse 本身拥有完整的本地工作区，**不安装、不启动、不连接 Orbit 也可以独立使用**。Orbit 是可选的跨应用检索、同步与 Nexus 家族联动能力，不是 Muse 的启动条件或数据所有者。

- `source = muse`
- 核心对象：灵感、任务与工作留痕、会议记录、剪贴板片段
- 产品形态：托盘常驻 + 快捷浮层 + 按需展开的轻量管理页
- 平台目标：Windows + macOS；移动端在桌面产品稳定后补充
- 设计稿与可交互原型：[`design/muse`](../../design/muse/README.md)

> **当前开发边界**：M3 已验证“独立 Muse 客户端 → Memory Protocol → Orbit”的最小文字写入链路。后续开发不再以 M3 单输入框为产品界面，而是围绕本文定义的四个快捷场景逐步产品化。界面先行，但实现仍按“灵感捕捉 → 任务留痕 → 会议 → 剪贴板 → 协作”的顺序分期交付。

## 1. 产品定位

### 1.1 Muse 是什么

Muse 是一个**触发式助手**，而不是另一个常驻在前台的全尺寸效率工作台。

用户通常不会“打开 Muse 看看”，而是在某个明确时刻直接召唤它：

1. 灵感出现时，立即记录；
2. 收到任务时，建立待办并绑定任务来源；
3. 会议开始时，立即录音并在结束后生成摘要；
4. 需要对照多段复制内容时，打开固定的剪贴板比较窗。

因此 Muse 的首要体验指标不是“页面有多少功能”，而是：

- **到达快**：任意功能可由独立快捷键直接唤起；
- **占用小**：默认窗口只呈现完成当前动作所需的内容；
- **退出轻**：提交、失焦或 `Esc` 后即可离开；
- **找得回**：内容自动携带时间、来源、关联对象与后续活动；
- **不打断**：AI 整理、转写和同步尽量在后台完成。

### 1.2 与 Nexus 家族的分工

| 维度 | Muse 的职责 | 交给其他软件 |
|---|---|---|
| 即时输入 | 文字、语音、任务、剪贴板的低摩擦捕获 | —— |
| 工作上下文 | 任务、来源证据、进展和交付物的绑定 | Orbit 负责跨源统一检索 |
| 会议 | 录音、转写、摘要、行动项回填 | Quill 负责长篇整理与正式文档 |
| 屏幕素材 | 接收用户主动粘贴或关联的素材 | Echo 负责连续屏幕捕获与 OCR |
| 深度书写 | 只做轻编辑与摘要修正 | Quill 负责长文、双链和知识网络 |
| 复习与知识消费 | 提供可检索材料 | Orbit 负责卡片、复习和全库问答 |

Muse 允许“就地找回与继续工作”，但不复制 Orbit 的全库工作台，也不复制 Quill 的完整编辑器。

### 1.3 产品原则

1. **快捷键先于导航**：导航用于回看，快捷键用于做事。
2. **一个浮层，一个主任务**：同一浮层只保留一个主要动作。
3. **默认自动留痕**：时间、来源、附件和状态变化自动记录，减少补填。
4. **证据和任务绑定**：消息、截图、文档、链接、会议片段都应能成为任务的上下文。
5. **本地优先**：剪贴板、录音和草稿默认本机处理；上传与共享必须由用户明确触发。
6. **渐进展开**：捕捉界面极小，需要整理或追溯时再展开详情。

### 1.4 独立模式与可选连接

- Muse 默认创建本地工作区，灵感、任务、会议和剪贴板均先写入本机；
- Orbit 未运行时不显示阻断提示，也不禁用任何 Muse 核心功能；
- 用户可在设置中主动连接 Orbit，把选定内容同步为 Memory；
- 断开或撤销 Orbit 授权不会删除 Muse 本地内容；
- 同步失败只改变同步状态，不回滚已经成功的本机保存；
- 与 Quill、Echo 的跨应用引用同样属于可选增强。

## 2. 信息架构与窗口模型

### 2.1 五个界面层级

| 层级 | 用途 | 默认尺寸建议 | 是否常驻 |
|---|---|---:|---|
| 快捷启动条 | 在未绑定独立热键时选择功能 | `520 × 64` | 否 |
| 灵感浮层 | 输入一句或一小段灵感 | `560 × 188` | 否 |
| 任务留痕窗 | 查看任务列表与选中任务的证据时间线 | `760 × 560` | 按需 |
| 会议浮层 | 录音中的控制、标记与实时转写 | `560 × 196` | 录音期间 |
| 剪贴板比较窗 | 固定在工作区一侧，对照多条复制内容 | `720 × 480` | 可置顶 |

设置页属于低频界面，从托盘或快捷启动条进入，不参与日常主流程。

### 2.2 快捷键模型

快捷键必须可自定义，并允许每个功能独立绑定：

| 动作 | 默认建议 | 行为 |
|---|---|---|
| 打开 Muse / 功能选择 | `Ctrl/Cmd + Shift + Space` | 打开快捷启动条 |
| 记录灵感 | `Ctrl/Cmd + Shift + I` | 光标直接进入灵感输入框 |
| 新建任务 | `Ctrl/Cmd + Shift + T` | 打开新任务浮层 |
| 开始/停止会议录音 | `Ctrl/Cmd + Shift + R` | 首次开始，再次停止 |
| 打开剪贴板比较 | `Ctrl/Cmd + Shift + V` | 显示并置顶剪贴板窗 |

规则：

- 冲突时必须在绑定现场提示，不等用户使用时才失败；
- 快捷键可只启用其中一部分；
- 功能浮层记住上次屏幕与位置，但默认在当前活动屏幕居中；
- `Esc` 关闭，`Ctrl/Cmd + Enter` 确认，`Tab` 顺序清晰；
- 录音快捷键在录音中必须有可感知的系统级状态。

## 3. 核心功能

### 3.1 灵感捕捉

**目标**：从“想到”到“记录完成”不超过两秒。

主要能力：

- 快捷键直达输入框，无启动页和表单标题；
- 支持纯文本、换行、轻 Markdown 和 `#标签`；
- 可一键切换短语音输入，转写后允许快速修正；
- 回车提交、`Shift + Enter` 换行；行为可在设置中调整；
- 失焦时自动保存草稿，避免灵感丢失；
- 自动记录捕捉时间、设备与捕捉方式；
- 提交后以低干扰状态提示“已收好”，随后隐藏。

灵感先写入 Muse 本地工作区。连接 Orbit 且用户开启同步后，再投影为 `Memory(kind=idea, source=muse)`，供跨应用检索或整理为 Quill 笔记。

### 3.2 待办、任务与工作留痕

**目标**：不仅记住“要做什么”，还保留“为什么做、谁提出、依据是什么、后来如何变化”。

#### 3.2.1 任务内容

每个任务至少包含：

- 标题；
- 状态：待处理 / 进行中 / 等待 / 已完成 / 已归档；
- 截止时间与提醒；
- 提出人、协作者（可选）；
- 所属项目或标签；
- 来源说明；
- 工作证据时间线。

#### 3.2.2 来源绑定

创建任务时可以把以下内容绑定到任务：

- 粘贴的微信、钉钉、邮件或聊天文字；
- 截图、文档、表格和本地文件；
- 网页链接；
- 某段会议转写或行动项；
- 剪贴板中的一个片段；
- 来自 Echo、Quill 或 Orbit 的 Memory。

Muse 不依赖平台聊天记录的永久可访问性。最小可行方案是由用户主动粘贴或拖入关键内容，Muse 同时记录：

- 原始文本或文件引用；
- 来源应用与来源类型；
- 捕捉时间；
- 用户补充的提出人和上下文；
- 内容哈希，避免重复绑定。

#### 3.2.3 工作时间线

任务详情采用不可打乱的时间线，自动与手动事件统一显示：

- 任务建立；
- 添加来源；
- 状态改变；
- 进展备注；
- 文件版本或交付物；
- 完成时间；
- 重新打开与变更原因；
- 会议或讨论产生的新决定。

当完成后再次出现问题，用户可以直接进入任务，按时间看到当时的要求、过程、交付物和后续变更，而不必重新在多个聊天软件里搜索。

#### 3.2.4 完成与复开

- 完成任务时可补充“完成说明”和交付物；
- 完成不会冻结内容，后续更新追加为新事件；
- 复开必须保留原完成时间，并记录复开原因；
- 任务搜索同时命中标题、来源文字、进展、文件名和参与人。

#### 3.2.5 多人交互（后续）

协作阶段在单人留痕模型上扩展，不另建割裂的数据结构：

- 任务可分派给联系人或团队；
- 评论、状态变化、附件和确认都进入同一时间线；
- 支持 `@提及`、已读、变更通知与任务交接；
- 权限按任务和附件控制；
- 服务端同步采用端到端加密或自托管方案；
- 未安装 Muse 的成员可通过受限分享页查看或回复。

界面设计当前预留参与人、评论入口和活动类型，但首期不伪造在线协作能力。

### 3.3 会议录音与摘要

**目标**：在不打断会议的前提下可靠记录，并在会后快速得到可核对的结论与行动项。

录音中：

- 快捷键开始/停止；
- 显示录音时长、音量状态与麦克风来源；
- 实时转写可开关；
- 支持添加“重点标记”，方便会后回听；
- 窗口可最小化为状态胶囊，但录音状态持续可见；
- 异常中断时保留已录部分并可恢复。

录音后：

- 生成全文转写；
- 生成简明摘要、议题、结论、风险和未决问题；
- 从转写中提取行动项，用户确认后转为 Muse 任务；
- 每个摘要句和行动项保留转写时间戳，可跳回原音频核对；
- 支持编辑说话人名称；
- 可导出为 Markdown，或整理为 Quill 会议笔记。

默认使用本地转写；云端模型是可选能力，并按录音明确提示数据去向。

### 3.4 剪贴板收集与多项比较

**目标**：把多次复制的条目固定在同一个窗口里，减少来回切换与人工记忆。

主要能力：

- 快捷键打开一个可置顶的剪贴板窗口；
- 保留最近复制的纯文本、富文本、链接和小型图片；
- 用户可把条目钉住，未钉住条目按容量或时间自动清理；
- 多选两项进入左右比较；超过两项时以列或紧凑列表对照；
- 文本比较突出新增、删除和修改片段；
- 支持逐行、逐词和“仅看差异”；
- 可在比较结果中复制某一侧、合并选中行或保存为任务证据；
- 敏感应用排除、暂停监听和一键清空必须始终可达。

剪贴板历史默认是**本地临时数据**，不会自动进入 Orbit。点击“保存”“绑定任务”或“转为灵感”只保证写入 Muse 本地工作区；是否继续同步为 Memory 由连接与同步设置决定。

### 3.5 快捷启动条与托盘

如果用户记不住所有快捷键，可先打开快捷启动条：

- 四个功能并列：灵感、任务、会议、剪贴板；
- 每项显示当前绑定按键；
- 支持键盘方向键和数字键选择；
- 托盘菜单提供相同入口、连接状态、暂停剪贴板、录音状态和退出；
- 没有促销、资讯流、统计大卡片或多层导航。

## 4. 关键交互流程

### 4.1 灵感

```text
按下“记录灵感”快捷键
  → 浮层出现并自动聚焦
  → 输入或语音
  → Enter / Ctrl+Enter 提交
  → 写入 Muse 本地工作区，原位显示“已收好”
  → 可选：后台同步到 Orbit
  → 浮层隐藏
```

### 4.2 任务与来源

```text
收到任务
  → 复制原始消息或拖入附件
  → 按下“新建任务”快捷键
  → Muse 自动带入剪贴板作为待确认来源
  → 补充标题、截止时间、提出人
  → 建立任务并生成第一条时间线
  → 后续进展、交付物、变更持续追加
  → 完成后仍可检索、复开和追溯
```

### 4.3 会议

```text
按下录音快捷键
  → 显示录音浮层
  → 录音 / 实时转写 / 重点标记
  → 再按快捷键停止
  → 本地保存音频并生成转写
  → 生成摘要与行动项
  → 用户确认行动项
  → 创建任务并绑定对应转写时间戳
```

### 4.4 剪贴板比较

```text
依次复制多个条目
  → 按下剪贴板快捷键
  → 条目集中显示并可置顶
  → 选择两个或多个条目比较
  → 查看差异、复制结果或合并
  → 可选：绑定任务 / 转为灵感 / 清除
```

## 5. 数据与关联

### 5.1 现有 Memory 模型映射

Muse 本地对象是独立模式的事实来源。连接 Orbit 后，为避免扩大核心枚举，首期将选定本地对象投影为现有 Memory 类型，并由 `meta.muse_type` 区分 Muse 业务对象：

| Muse 内容 | Memory `kind` | `meta.muse_type` | 写入规则 |
|---|---|---|---|
| 灵感 | `idea` | `idea` | 提交后立即写入 |
| 任务根记录 | `note` | `task` | 创建任务时写入 |
| 任务进展/证据 | `note` / `clip` / `file` | `task_activity` / `task_evidence` | 通过 `Link(references)` 关联任务 |
| 会议 | `voice` | `meeting` | 音频、转写、摘要在同一根记录下 |
| 剪贴板临时项 | 不写入 | `clipboard_item` | 仅保存在本地临时库 |
| 已保存剪贴板 | `clip` | `clipboard_saved` | 用户明确保存后写入 |

当任务协作进入实现阶段，再评估是否新增一等 `Task`、`Activity` 与权限模型；当前界面不以尚未落地的数据能力作为依赖。

### 5.2 Muse `meta` 约定

```jsonc
{
  "muse_type": "task",
  "capture_method": "clipboard",
  "status": "doing",
  "due_at": "2026-07-29T10:00:00+08:00",
  "requester": {
    "name": "林然",
    "channel": "dingtalk"
  },
  "source_context": {
    "app": "DingTalk",
    "captured_at": "2026-07-26T14:08:00+08:00",
    "content_hash": "sha256:..."
  },
  "processed": false,
  "draft": false
}
```

### 5.3 任务关联

- 任务根记录负责稳定身份、标题、状态与截止时间；
- 来源、文件、会议片段和进展分别保留原始内容；
- 通过 `Link(references)` 从任务指向证据；
- 由会议行动项创建的任务，同时保留 `derived_from` 到会议记录；
- 修改来源不得覆盖旧证据，应追加版本或活动；
- 删除任务时默认只归档任务，不连带删除原始 Memory。

### 5.4 本地临时数据

剪贴板缓存、未提交草稿和录音中的临时分片不进入共享记忆库：

- 使用应用私有目录；
- 静态数据加密；
- 可配置最大条数、保留时间和排除应用；
- 退出时是否清理可配置；
- 用户清空后写入删除标记并尽快清理文件。

## 6. 技术实现边界

### 6.1 应用形态

Muse 使用 Tauri 2.0：

- **React + TypeScript + `@nexus/ui`**：浮层、任务留痕、会议状态、剪贴板比较和设置；
- **Rust/Tauri**：全局热键、托盘、窗口置顶、剪贴板、录音、权限与本地临时库；
- **Muse 本地工作区**：独立保存灵感、任务、会议、剪贴板与活动时间线；
- **Memory Protocol（可选）**：同步选定的 Muse 内容、建立跨应用关联、监听授权状态；
- **`nexus-core`**：ingest、检索、加密媒体、转写与事件。

```text
全局快捷键 / 托盘
        ↓
Muse 窗口路由（idea / task / meeting / clipboard）
        ↓ Tauri IPC
平台能力（Hotkey / AudioRecorder / Clipboard / Window）
        ↓
Muse 本地工作区（始终可用）
        ↓ 可选
Memory Protocol + nexus-core
        ↓
Orbit 检索 / Quill 整理 / 后续协作同步
```

### 6.2 性能目标

| 指标 | 目标 |
|---|---:|
| 已常驻时浮层出现 | `< 120ms` |
| 冷启动可输入 | `< 500ms` |
| 提交后的本地确认 | `< 100ms` |
| 空闲内存 | 以最小 Tauri/WebView 基线为目标，持续监测 |
| 剪贴板更新显示 | `< 150ms` |
| 录音开始反馈 | `< 200ms` |

本地写入成功就是保存成功。Orbit 同步、转写与 AI 摘要不应阻塞浮层关闭；后台队列负责可选任务的失败重试和状态回显。

### 6.3 权限与降级

| 能力不可用 | 降级 |
|---|---|
| Orbit 未运行或授权失效 | Muse 核心功能不受影响；已开启同步的内容保留本机状态，连接恢复后可补写 |
| 麦克风无权限 | 会议界面解释原因并提供系统设置入口；文字能力不受影响 |
| 本地转写模型未安装 | 仅保存音频，后台安装或切换云端后补转写 |
| 快捷键冲突 | 绑定时检测并要求更换 |
| 剪贴板监听暂停 | 保留已钉住条目，明确显示暂停状态 |
| AI 摘要失败 | 完整录音和转写仍可用，可手动重试 |

## 7. 界面与视觉要求

Muse 遵循 [`docs/design-system.md`](../design-system.md)，并针对小助手形态补充：

- 默认暗色；以边框和表面明度表达层级，不使用大面积渐变；
- 桌面主窗口使用 38px 自定义标题栏，展示正式 Muse 图标、本地状态和原生语义的最小化/最大化/关闭按钮；
- 原生窗口装饰关闭后，标题栏必须保留可拖动区域、双击最大化、键盘焦点和高对比关闭态；
- 浮层圆角 `10px`，主输入和工具栏控件高度 `28–32px`；
- 正文字号 `13px`，元数据 `11–12px`；
- 单个浮层最多一个主色按钮；
- 功能图标统一 16px 线性图标，应用图标使用“星芒 M”标识；
- 悬停时再显示次级动作，避免每行都有按钮；
- 任务详情使用紧凑时间线，不使用大卡片瀑布流；
- 剪贴板比较用等宽内容区域和清晰的增删标记；
- 录音状态除了颜色，还必须显示文字和计时；
- 所有功能均支持键盘焦点、`prefers-reduced-motion` 和 390px 窄窗口适配。

设计原型定义六个可预览状态：

1. 快捷启动；
2. 灵感捕捉；
3. 任务与工作留痕；
4. 会议录音与摘要；
5. 剪贴板比较；
6. 快捷键设置。

## 8. 设置项

| 分类 | 设置 | 默认 |
|---|---|---|
| 快捷键 | 启动条、灵感、任务、会议、剪贴板独立绑定 | 见 §2.2 |
| 浮层 | 位置、屏幕、失焦行为、提交后隐藏 | 当前屏幕居中、提交后隐藏 |
| 灵感 | Enter 行为、草稿、默认标签 | Enter 提交、保留草稿 |
| 任务 | 默认项目、完成说明、提醒 | 无默认项目、完成说明可选 |
| 会议 | 麦克风、语言、实时转写、摘要模型 | 系统麦克风、本地转写 |

| 隐私 | 云端处理、崩溃日志、敏感内容清理 | 云端关 |
| 同步 | 纯本地 / E2E 云 / 自托管 | 纯本地 |

## 9. 分阶段开发计划

| 阶段 | 范围 | 完成标志 |
|---|---|---|
| **界面基线** | 新视觉、应用/功能图标、五类窗口原型、快捷键设置 | 设计稿评审通过，桌面与窄窗口无溢出 |
| **一期：极速捕捉** | 托盘、独立热键、灵感浮层、草稿、本地工作区、可选 Orbit 同步 | 任意应用中两秒内完成记录，Orbit 未运行也可完成 |
| **二期：任务留痕** | 任务状态、来源绑定、附件、活动时间线、搜索、复开 | 可从任务直接还原要求、进展和交付物 |
| **三期：会议** | 录音、转写、重点标记、摘要、行动项转任务 | 摘要可回链音频时间戳，行动项可确认 |
| **四期：剪贴板** | 历史、置顶、两项/多项比较、差异、高敏排除 | 多条内容无需切窗即可准确比较 |
| **五期：协作** | 分派、评论、通知、权限、分享页、团队同步 | 任务在多人间交接仍保留完整时间线 |

M3 的最小来源代码作为一期的协议基础继续复用，但其单输入框界面不再作为产品形态延伸。

## 10. 验收指标

### 10.1 体验

- 用户可为四个核心功能分别绑定快捷键；
- 灵感捕捉从热键到提交不需要鼠标；
- 新任务能直接带入当前剪贴板作为待确认来源；
- 已完成任务可按标题、来源关键词、提出人和完成时间找回；
- 会议摘要的结论和行动项能跳到对应转写位置；
- 剪贴板窗可置顶，至少支持两项逐词比较；
- 临时剪贴板不会在未经确认时进入 Orbit。

### 10.2 可靠性

- 失焦、崩溃、服务未启动时不丢草稿；
- 录音异常结束时已录分片可恢复；
- 授权撤销后不泄露旧令牌，用户内容保留并可重连；
- 同一个来源重复绑定时能提示或合并；
- 任务复开不覆盖历史完成记录；
- 所有自动生成内容均保留原始材料和可核对位置。
